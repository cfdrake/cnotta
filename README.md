# Cnotta

Knitting row counter for iOS, written with SwiftUI and SwiftData.

![Cnotta, image 1](https://github.com/cfdrake/cnotta/blob/main/Screenshots/cnotta-1.png?raw=true) ![Cnotta, image 2](https://github.com/cfdrake/cnotta/blob/main/Screenshots/cnotta-2.png?raw=true) ![Cnotta, image 3](https://github.com/cfdrake/cnotta/blob/main/Screenshots/cnotta-3.png?raw=true)

## Features

- Create any number of projects with their own counter
- Simple "+" and "-" buttons with haptic feedback to count rows
- Long-press "-" to reset counter
